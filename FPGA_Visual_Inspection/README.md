# FPGA实时视觉与缺陷检测系统

基于易灵思 **Ti60 FPGA** 与 **SC2210 MIPI摄像头** 的实时视觉原型，实现视频预处理、Sobel边缘检测、基本图形识别、T形五孔连接板几何缺陷检测，以及DDR连续录制回放。系统通过HDMI输出处理画面和检测结果，运行时无需PC参与图像计算。

项目以官方MIPI采集、DDR读写及HDMI显示例程为基础，扩展图像处理、几何分析、交互与回放功能。检测采用数字逻辑和几何规则，无需训练神经网络或预先采集固定位置的良品图像模板。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 视频输出 | 1920×1080、60Hz HDMI输出 |
| 画面校正 | 固定增益白平衡、自动曝光 |
| 图像预处理 | 灰度化、3×3高斯滤波、Sobel边缘提取、3×3邻域去毛刺 |
| 分屏显示 | 左半幅显示对应区域的灰度图，右半幅显示对应区域的边缘图 |
| 基本图形识别 | 圆形、矩形、三角形及正六边形候选识别，支持平面内旋转搜索及分类着色 |
| 连接板检测 | 根据五孔布局、孔径和外轮廓判断合格状态，并标记异常区域 |
| 图像录制回放 | 连续录制100帧，支持暂停、逐帧浏览及循环回放 |
| 按键交互 | 工作模式切换、Sobel阈值调节、录制回放控制 |

60Hz指显示输出刷新率，不代表每秒完成60次独立几何判定；帧级分析的更新速度取决于目标数量和轮廓复杂度。

## 系统处理流程

摄像头RAW8数据经MIPI接收后写入DDR，由显示侧读出，再进行RAW8到RGB888转换和白平衡处理。RGB数据进入灰度化、高斯滤波、Sobel及邻域抑噪链路，形成显示和检测所需的边缘图。

检测分为两条独立支路：

- **通用形状识别**：右半幅边缘图经过4×4区域OR下采样，形成240×270二值图，采用队列式8邻域连通域搜索，并通过半径带、旋转投影、多方向支撑线和边角证据完成候选分类。
- **连接板检测**：提取候选孔的孔心与估计孔径，利用五孔相对布局建立工件局部坐标关系，再检查孔位、孔径及外轮廓。几何分析使用480×540下采样边缘图。

录制通路保存RAW8数据；回放时通过后续图像处理链路形成显示画面，不直接存储已经叠加标记的HDMI画面。录制和回放期间暂停自动曝光更新。

## T形五孔连接板检测

检测对象为具有五孔布局及规定外轮廓的平面连接板。系统结合孔位关系估计目标位置、方向和尺度，使用有界轮廓校正适应一定的位置及姿态变化。

| 样件 | 缺陷类型 | 检查内容 |
| --- | --- | --- |
| A | 无缺陷对照件 | 孔洞布局、孔径与外轮廓完整性 |
| B | 孔洞缺失 | 预期孔位是否存在有效候选孔 |
| C | 孔位偏移 | 孔中心相对理论位置的偏差 |
| D | 孔径异常 | 尺度换算后的估计孔径 |
| E | 底边缺口 | 底部边界的局部缺失 |
| F | 顶部截短 | 顶部边界的位置与覆盖情况 |
| G | 斜边锯齿状缺陷 | 斜边轮廓起伏与局部差分特征 |

候选孔是满足初步圆形条件的轮廓，不等同于连接板上的真实孔。模块最多保存16个候选孔，后级再依据五孔布局进行匹配。

测试时应使目标完整入镜、无遮挡，优先放在右半幅检测区域内，并尽量使零件平面与成像平面平行。照明、阴影、反光、目标大小及轮廓断裂都会影响结果。该系统用于可见外形和孔洞检测，不进行内部探伤或完整三维测量。

## 编译与运行

1. 获取完整工程，保留工程文件、源码、IP配置、接口配置和约束之间的相对路径。
2. 使用Efinity打开Ti60_Demo.xml，确认器件、文件列表、引脚与时钟配置正确。
3. 检查DDR、FIFO、MIPI等依赖是否齐全；若工具提示重新生成IP，按对应工具流程处理。代码引用的.vh、.mem及.hex文件应一并保留。
4. 依次完成综合、布局布线和时序分析，检查报告后生成bitstream。
5. 断电连接摄像头及HDMI显示器，连接下载器并上电，下载对应bitstream。
6. 等待摄像头初始化及自动曝光稳定，检查显示器输入信息，再通过K1/K2选择工作模式、调节阈值或进行录制回放。

按键短按、长按的具体动作由system_ui_controller及回放控制逻辑定义，使用时以当前源码为准。

## 参数与调试

- **白平衡**：采用Q8定点增益，256代表1.0。原白光参数为R/G/B＝320/256/384；不同光源下可重新标定。该功能不等同于自动白平衡。
- **Sobel阈值**：初值14，可调范围1～255；降低阈值可保留弱边缘，也可能增加噪点。
- **录制容量**：RECORD_FRAMES＝100。
- **回放节拍**：PLAY_HOLD_FRAMES＝6；在60Hz输出下，自动回放约每秒前进10个存档帧。
- **时钟对齐**：像素处理模块使用clk_pixel_2x域，新增处理阶段时需同步延迟RGB/灰度数据及VSYNC、HSYNC、DE。
